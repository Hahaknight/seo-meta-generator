# SEO Meta Tags Generator

**Generate title, description, Open Graph and Twitter Card tags — with live Google and social previews. Free, no signup.**

🔗 **Use it online: <https://hahaknight.github.io/seo-meta-generator/>**

## Why this exists

Meta tags are the cheapest SEO you'll ever write, and the easiest to get wrong: titles that truncate at 60 characters, descriptions that Google rewrites, social cards that render as bare links. This tool shows you **exactly how your tags will look** before you ship them:

- **Google preview** — SERP-style rendering with live length feedback, so you see truncation before Google's crawler does
- **Social card preview (Open Graph)** — how your link unfurls in Slack, LinkedIn, iMessage
- **Your tags** — copy-paste-ready `<title>`, `<meta name="description">`, OG and Twitter Card markup

Everything runs **in your browser** — no signup, no server, nothing sent anywhere.

## Self-host

Single static `index.html`, zero dependencies.

git clone https://github.com/Hahaknight/seo-meta-generator
# open index.html directly, or enable GitHub Pages on your fork
